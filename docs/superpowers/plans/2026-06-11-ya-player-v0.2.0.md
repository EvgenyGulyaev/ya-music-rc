# Ya Player v0.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add track seek/progress, search, lighter wave presets, cleaner header, compact playback mode label, and larger favorite-list text without album covers.

**Architecture:** Keep the current single native egui app. Extend `AudioPlayer` with rodio position/duration/seek helpers, extend Yandex API wrapper with search, and keep wave presets text-only to preserve low memory use.

**Tech Stack:** Rust, egui/eframe, rodio, reqwest blocking, GitHub Actions release pipeline.

---

### Task 1: Playback Progress

**Files:** `src/audio.rs`, `src/app.rs`, `src/player.rs`, `tests/player_tests.rs`

- Add `AudioPlayer::position`, `duration`, and `seek` using rodio `Player::get_pos`, `Source::total_duration`, and `Player::try_seek`.
- Add a compact seek slider and `mm:ss / mm:ss` time label to the bottom player bar.
- Keep status messages out of the top header.

### Task 2: Search

**Files:** `src/api.rs`, `src/app.rs`, `tests/api_tests.rs`

- Add `YandexMusicClient::search_tracks(query)` using `/search?text=...&type=track`.
- Parse track search results into existing `TrackSummary`.
- Add search input and results list. Clicking a result starts playback from search queue.

### Task 3: Wave Presets

**Files:** `src/app.rs`, `src/api.rs`, `tests/api_tests.rs`

- Rename wave play button to `Моя волна`.
- Add text-only preset/station buttons from `wave_stations`; no artwork.
- Add `Перемешать` by reloading the selected station/session.

### Task 4: UI Cleanup

**Files:** `src/app.rs`, tests in `src/app.rs`

- Remove redundant `Ya Player` label from the in-app header.
- Replace `Режим: Дальше` with `След` and `Повтор`.
- Increase favorite row font size.

### Verification

- Run `cargo fmt`.
- Run `cargo test --locked`.
- Run `cargo check --locked`.
- Run local macOS package script.
- Commit normally and push `main`; release workflow creates the next version automatically.
